\section{Problem Setup}
% ============================================================

Each customer journey is a sequence of discrete actions $a_1, a_2, \ldots, a_n$
recorded at continuous timestamps. The goal is to predict, from a partially
observed prefix, whether the journey will reach the success state
(action \texttt{ed\_id} = 28, \emph{order\_shipped}) within a 60-day horizon.

We model journeys as realizations of a \emph{Continuous-Time Markov Chain}
(CTMC) on the action-type state space $\mathcal{S} = \{s_1, \ldots, s_K\}$.
The key quantity is the \textbf{generator matrix} $Q \in \mathbb{R}^{K \times K}$
with entries
\[
    q_{ij} = \begin{cases}
        \lambda_{ij} \geq 0 & i \neq j \\
        -\sum_{j \neq i} \lambda_{ij} & i = j
    \end{cases}
\]
where $\lambda_{ij}$ is the instantaneous rate of transitioning from state $i$
to state $j$.

\subsection*{Inference target}

Given current state $s$ at snapshot time, we want
\[
    P\!\left(T_{\text{success}} \leq \tau \mid X(0) = s\right)
    = \left[e^{Q^* \tau}\right]_{s,\,s^*}
\]
where $\tau = 60 \times 86400$ seconds, $s^* = 28$ is the absorbing success
state, and $Q^*$ is the generator with row $s^*$ zeroed out (making success
absorbing).

% ============================================================
\section{Model 1: Global CTMC}
% ============================================================

\subsection{Overview}

A single generator matrix $Q$ is estimated from all training journeys pooled
together. This is the simplest model and serves as the baseline for the others.

\subsection{Fitting}

Let $\mathcal{D}$ be the set of all consecutive-state transitions
$(i, j, \Delta t)$ extracted from training journeys. Define:

\[
    N_{ij} = \#\{(i,j,\cdot) \in \mathcal{D}\}, \qquad
    T_i = \sum_{(i,j,\Delta t)\,\in\,\mathcal{D}} \Delta t
\]

The maximum-likelihood estimate of the off-diagonal rates is
\[
    \hat{\lambda}_{ij} = \frac{N_{ij}}{T_i}, \quad i \neq j
\]
with diagonal entries set to $q_{ii} = -\sum_{j \neq i} \hat{\lambda}_{ij}$.
Self-transitions are discarded before counting.

\subsection{Prediction}

\paragraph{Absorption probability.}
The success state $s^* = 28$ is made absorbing by zeroing row $s^*$ in $Q$.
For a journey currently in state $s$, the predicted probability is:
\[
    \hat{p}(s) = \left[e^{Q^* \tau}\right]_{s,\,s^*}
\]
computed via the matrix exponential (\texttt{scipy.linalg.expm}).

\paragraph{Expected hitting time.}
For transient states $\mathcal{T} = \mathcal{S} \setminus \{s^*\}$, the
expected time to absorption satisfies the linear system
\[
    Q_{\mathcal{T}} \, m = -\mathbf{1}
\]
where $Q_{\mathcal{T}}$ is the sub-matrix of $Q$ restricted to transient rows
and columns. Solving gives the expected seconds to success from each state.

\paragraph{Fallback.}
If the current state of a test journey was never seen during training, the
model falls back to the empirical success prior implied by the transition count
table.

\section{Model 2: Laplace-Smoothed Global CTMC}
% ============================================================

\subsection{Overview}

The global CTMC can produce noisy rates for rarely-observed state pairs because
$N_{ij}$ is often zero. \texttt{LaplaceGlobalCTMC} adds pseudo-counts to
regularize the generator.

\subsection{Fitting}

Before computing rates, every off-diagonal count cell receives an
$\alpha$-smoothing prior:
\[
    \tilde{N}_{ij} = N_{ij} + \alpha, \quad i \neq j
\]
with $\alpha = 0$ recovering the unsmoothed model, $\alpha = 1$ giving
standard Laplace smoothing, and $\alpha = 0.5$ (default) corresponding to the
Jeffreys prior. Rates are then computed as before:
\[
    \hat{\lambda}_{ij} = \frac{\tilde{N}_{ij}}{T_i}
\]

\subsection{Prediction}

Identical to Global CTMC. Because the generator is denser (no true zeros for
unseen pairs), the matrix exponential tends to assign nonzero probability to
every reachable state, reducing the variance of absorption probability
estimates for rare states.

\section{Model 3: Clustered CTMC}
% ============================================================

\subsection{Overview}

Rather than pooling all journeys into one $Q$, customers are grouped into $K$
behavioral clusters and a separate \texttt{GlobalCTMC} is fit per cluster. The
intuition is that different customer types (e.g., browsers vs.\ decisive
buyers) have different transition dynamics, and a per-segment $Q$ captures
this heterogeneity.

\subsection{Clustering}

\paragraph{Feature extraction.} For each journey prefix, the following
features are computed without using the outcome label (no leakage):
\begin{itemize}
    \item Proportion of each of the top-20 most frequent actions
          (\texttt{action\_prop\_\{ed\_id\}}).
    \item Entry state (\texttt{first\_state}) and current state
          (\texttt{current\_state}).
\end{itemize}

\paragraph{K-Means.} Features are imputed (median) and standardized, then
$K$-Means with $K=3$ clusters (default) is fit on the combined feature matrix.

\subsection{Fitting}

Transitions are partitioned by cluster assignment, and a \texttt{GlobalCTMC}
is fit independently on each partition:
\[
    Q^{(k)} = \texttt{GlobalCTMC.fit}\!\left(\mathcal{D}_k\right), \quad
    k = 1,\ldots,K
\]

\subsection{Prediction}

At test time:
\begin{enumerate}
    \item Compute the same feature vector for the test journey.
    \item Assign it to cluster $k^*$ via the fitted K-Means pipeline.
    \item Use $Q^{(k^*)}$ to compute the absorption probability.
    \item If $k^*$ has no fitted model (unseen cluster), fall back to the
          global model.
\end{enumerate}

\paragraph{Blended submission.} In the final Kaggle submission, the global and
clustered predictions are averaged:
\[
    \hat{p}_{\text{blend}}(s) = 0.5\,\hat{p}_{\text{global}}(s)
    + 0.5\,\hat{p}_{\text{clustered}}(s)
\]

\section{Model 4: Calibrated CTMC}
% ============================================================

\subsection{Overview}

All CTMC models output absorption probabilities that reflect dynamics in the
\emph{training} data. Because the Kaggle test set has a much lower success
prevalence ($\approx 5\%$) than training ($\approx 22\%$), raw probabilities
are systematically over-confident.

\texttt{CalibratedCTMC} is a post-hoc wrapper that corrects this in two
complementary ways.

\subsection{Isotonic Calibration}

An isotonic regression is fit on a held-out calibration fold:
\[
    \hat{f} = \arg\min_{f \text{ non-decreasing}} \sum_i (y_i - f(\hat{p}_i))^2
\]
Because isotonic regression minimizes squared error, fitting it directly
minimizes the Brier score on the calibration set --- the Kaggle evaluation
metric.

At test time, raw predictions are passed through $\hat{f}$:
\[
    \hat{p}_{\text{cal}}(s) = \hat{f}\!\left(\hat{p}_{\text{raw}}(s)\right)
\]

\subsection{Prevalence Shift (Log-Odds Adjustment)}

A simpler but complementary correction is applied uniformly to all model
outputs before submission. Let $\pi_{\text{train}}$ and $\pi_{\text{test}}$
be the success rates in training and test respectively. Using a Bayes
prior-probability adjustment in log-odds space:
\[
    r = \frac{\pi_{\text{test}} / (1 - \pi_{\text{test}})}
             {\pi_{\text{train}} / (1 - \pi_{\text{train}})}
    \approx 0.188
\]
\[
    \hat{p}_{\text{adj}} = \frac{\hat{p} \cdot r}{\hat{p} \cdot r + (1 - \hat{p})}
\]
This is applied in \texttt{calibrate\_prevalence()} in
\texttt{tabular\_submission.py} to every model's output
($\pi_{\text{train}} = 0.2194$, $\pi_{\text{test}} = 0.05018$, estimated from
the all-zeros Kaggle Brier score).

% ============================================================
\section{Model Hierarchy and Composition}
% ============================================================

The four models build on one another as follows:

\begin{center}
\begin{tabular}{lll}
\toprule
Model & Builds on & Key addition \\
\midrule
\texttt{GlobalCTMC}         & ---             & Single pooled $Q$; MLE rates \\
\texttt{LaplaceGlobalCTMC}  & GlobalCTMC      & Add-$\alpha$ smoothing on $N_{ij}$ \\
\texttt{ClusteredCTMC}      & GlobalCTMC      & Per-segment $Q^{(k)}$ via K-Means \\
\texttt{CalibratedCTMC}     & Any CTMC model  & Isotonic + prevalence shift \\
\bottomrule
\end{tabular}
\end{center}

The submission pipeline (\texttt{ctmc\_submission.py}) always applies
\texttt{calibrate\_prevalence} to all outputs. \texttt{CalibratedCTMC}
(isotonic) is used for offline Brier diagnostics in
\texttt{ctmc\_advanced.py}.

\section{Inference Summary}
% ============================================================

All models share the same two prediction modes:

\begin{description}
    \item[Absorption probability] $\hat{p}(s) = [e^{Q^*\tau}]_{s,s^*}$ ---
    the direct estimate of $P(\text{success within } \tau \mid \text{current state}=s)$.
    Used as the primary Kaggle submission score.

    \item[Expected hitting time] $\hat{m}(s)$ from $Q_\mathcal{T} m = -\mathbf{1}$
    --- used experimentally in \texttt{ctmc\_waiting\_time\_\allowbreak{}experiment.py} to
    compare against the absorption probability as a ranking signal
    (transformed as $e^{-\hat{m}/\tau}$).
\end{description}
